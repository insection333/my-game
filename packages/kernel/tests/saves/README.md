# Sample saves

One stored save of every save-format version, kept for good. Tests load each one against the current code, so an old player's save can always be read. Never edit or regenerate these; when `SAVE_VERSION` goes up, add `vN.json` beside them.

- `v1.json`: three hours into a game, with every lane used, a queued Next action, stopped lanes, feature data and remembered requests.
- `v2.json`: the same game in version 2 (session 6), which adds luck for Uncommon finds and the dates of first finds.
